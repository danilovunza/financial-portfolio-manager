# Financial Portfolio Manager

## Overview

The Financial Portfolio Manager is a Python application that helps investors manage and analyze investment portfolios.

The system supports stock tracking, return calculations, portfolio analysis, and risk evaluation.

---

## Features

* Stock Management
* Portfolio Tracking
* Return Calculations
* Profit/Loss Analysis
* Risk Metrics
* Portfolio Concentration Analysis

---

## Classes

### Asset

Base investment class.

### Stock

Represents stock investments.

### Portfolio

Manages investments and analysis.
